# 单位放置与补位规则

2026-09-09，按用户提供的规则替换旧版“独立居中两排单位”的行为。

- 行动阶段手牌小兵仍消耗法力，并要求当前线路存在可行动的同色英雄。
- `placementPositions` 是玩家目标高亮、AI 候选位置及引擎目标校验的共同来源。
- 若敌方某格有单位、己方同格为空，必须先填这些格；没有此类空缺时仅可在整条线路最左或最右扩展。空线路从位置 0 开始。
- 左端扩展的输入位置用 -1 表示；落位时将两边现有单位同时右移一格，再将新单位放到 0，保留原有对位关系。
- `compactLane` 只删除双方均为空的整列，不再独立移动某一排。单方阵亡留下的对位空格会保留。
- 自动生成、召唤、跨线移动及英雄回归的自动落位同样优先补对位空缺。显式 `spawn` 仍是底层场景构造接口，可供剧情初始布局与测试固定位置；从手牌放置必须经过 `play` 的完整校验。
- 无正对单位时攻击方向按左 25%、正前 50%、右 25% 抽取；即使邻格为空也保留方向。补入正对单位时恢复正对攻击，目标死亡或整列压缩造成目标变化时重算相关方向。
- 死亡小兵退出棋盘并进入弃牌记录，不加入英雄回归列表；部署 API 明确拒绝小兵和英雄复制体。死亡对象作为历史记录保留，供战斗动画和事件按 ID 查询，不能据此复活。
- 随机数继续使用可序列化的引擎随机种子，非法手牌操作整体回滚，包括随机数、法力与手牌。
